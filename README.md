# yogapp-audio-ja-keita

Unzipped ja-keita voice clips for SynthYoga Cast receivers, served at
https://syntithenai.github.io/yogapp-audio-ja-keita/v1/

Published by `apps/yoga/scripts/publish-voice-files.sh` in the yogapp repo.
The phone app downloads the same clips as a zip from
https://syntithenai.github.io/yogapp-audio-ja-keita/v1/ja-keita.zip
